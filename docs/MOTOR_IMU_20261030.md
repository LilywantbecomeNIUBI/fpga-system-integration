# 电机＋IMU接入与运动阶段入口

用户现场确认2026-10-30六段起步、停车、左右转基本正确。该反馈支持低速基本动作，不替代整题路线、转角、导航或高速验收。轮径65mm；约1500计数/圈仍为粗估，1m/s尚未达到。

## 数据与端口

- PC上位机8874：`/home`入口、`/motor`轮速及同页IMU面板（`#imu`）。刷新当前服务即可显示。`/imu`独立页在下次正常重启上位机后也可使用。
- Nano网关8873：现有本机配置选择的地址；电机与IMU共用Nano CH340 UART，115200 8N1，唯一串口拥有者仍为Nano。
- FPGA IMU：P7-39/F19 SCL、P7-40/F20 SDA，3.3V逻辑与共地；ICM42688 WHO_AM_I应为0x47。I2C采样1kHz、UART每20个样本取1个，即约50Hz。
- 视觉台沿用8872，图像UDP6102、事件6202等依配置；本次没有启动或宣称验证摄像头链路。IMU不需要另开PC串口或视频端口。

IMU面板显示新鲜状态、三轴加速度/角速度、主机估算俯仰与横滚及CRC/采样信息；过期清空读数，航向角未实现，IMU当前不参与电机控制。
