## 已修改的软件

- `fpga/imu/mpu6050_reader.v`：地址0x68；先检查WHO_AM_I=0x68，器件复位后再检查；默认上电、复位、唤醒各等待100ms；配置寄存器逐项读回。
- 总线请求400kHz，并强制限制不超过400kHz；复用的开漏主机在50MHz下名义SCL约379kHz，保留时钟拉伸、超时和总线恢复。
- SMPLRT_DIV=0，DLPF_CFG=1，1kHz，±4g（8192 LSB/g）与±1000dps（32.8 LSB/(°/s)）；温度为 raw/340+36.53℃。辅助主机、旁路和FIFO关闭。
- 轮询0x3A的DATA_RDY位，再从0x3B一次读取14字节；六轴与温度同时提交。MPU6050的0x8000是有效负满量程值，不继承旧ICM的无效值过滤规则。
- 保留3ms样本过期提示、10ms采样看门狗、NACK/超时/身份/回读失败诊断与自动重新初始化。序号表示成功读取次数，时间戳是观察时间，不保证等于芯片转换时间或不漏转换。
- 混合UART仍用v2/48字节帧，MPU配置ID=4、WHO=0x68、fast_bus=0；PC与Nano共用解析器按配置ID使用正确温度/角速度换算，旧ICM配置2/3仍可回放。
- `tools/build_system.py` 增加独立产物目录及对应网表/CDC审计；本次使用现有 `system_top` 与现行电机/编码器引脚表，不切换任务四M2引脚配置。

## 上板顺序

1. 断电后按VCC/Pin1方向安装新模块，保持电机动力支路断开。上电先检查模块无异常发热、SCL/SDA空闲为高、AD0为低。
2. 首次只用 `imu_check.fs` 做SRAM静态测试，先核对SHA256。此文不表示已下载。整机候选仍有原工程时序问题，不作为签核版；本轮不执行整机下载。
3. 配套Nano包在 `dist/mpu6050_revb_20261102/nano`，PC直接使用本仓库新版解析器。先更新网关解析器，再检查新配置ID；旧网关无法正确解释配置4。不改变模型、视觉目录、系统环境或串口所有权。
4. 检查版不输出电机遥测，使用下方 `--imu-only`；整机候选的后续检查去掉该参数并检查电机停机遥测。静止读取10秒，要求WHO=0x68、config_id=4、ready=1、fault/stale=0，CRC、I²C错误和丢帧计数为0，原始读取速率约1kHz，50Hz调试遥测，电机未解锁且输出为0。
5. 手动倾斜和旋转检查各轴符号与安装朝向。轴向保持传感器原始坐标，未凭旧模块安装方向推断新模块方向；随后做静止零偏/安装零点确认，再恢复整车并发测试。

独占PC串口时可使用以下只读工具（将COM号替换为实际端口；先关闭原串口占用者）：

```powershell
python tools/verify_mpu6050.py --port COM20 --seconds 10 --imu-only
```

它只接收，不发送串口字节或运动命令，保存 `results/mpu6050_时间戳/rx.bin` 和 `result.json`。离线验收已有UART记录可用 `--input 路径/rx.bin`，IMU检查版记录同时加 `--imu-only`。检查版的电机固定低由RTL、综合后网表与数字仿真确认，不把缺少电机遥测解释成已读到电机停机反馈。Nano网关已独占串口时沿用网关观测，不另开PC串口。新包仅准备，未部署。
