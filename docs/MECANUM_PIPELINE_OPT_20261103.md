# 麦轮 1kHz 控制流水优化（2026-11-03）

本分支修复轮速估计、PI 算术链、位置环求和三处实现热点。
本优化版本仅进行了离线仿真与源码冻结，没有启动综合、布局布线或硬件下载。
初始审查见 [超时与代码检查](BUILD_TIMEOUT_CODE_AUDIT_20261103.md)。

## 代码变更

- `fpga/motor/wheel_speed_hybrid.sv`：八桶历史改为固定尾端读出的移位队列，取消动态索引；
  桶容量按 1ms 内每个 FPGA 时钟最多出现一个 +/-2 编码器事件推导。
  在 50MHz 下，每桶位移为有符号 18 位、事件数 16 位，八桶总位移 21 位、事件数 19 位。
  将采样快照、移除旧桶、加入新桶、模式判定及速度归一化分级；
  乘 320 写为已分级的移位相加，输出保留有符号 Q8 每 10ms 单位。
  继续接收计算期间的新编码器事件；换向、clear、reset、故障会取消整个在途计算。
  桶溢出和下一采样到来时仍忙均锁存故障，避免缩位后静默截断。
  在周期测量分支，输出在采样后 35 个 FPGA 时钟内就绪；计数分支为 4 个时钟。
  原四轮核心的 40 时钟等待及共享双轮核心的 36 时钟等待均通过回归。
- `fpga/mecanum/wheel_control_1khz.sv`：比例/积分乘积明确为完整 39/37 位，
  前馈有符号结果 37 位、比例十倍缩放 43 位、比例加前馈 44 位。
  乘积、比例缩放、前馈合并和最终积分相加分配在不同的已有状态中，
  每级缩放/求和的输入均为寄存器；积分与最终累加仍保留 48 位。
  没有直接削减为可能溢出的 32 位。状态数量及输出时刻保持不变。
  维持原积分物理单位、抗饱和、斜坡、换向等待、零目标与立即禁止行为。
- `fpga/mecanum/mecanum_pose_control.sv`：在同一 tick 锁存四轮差分，
  下一拍两两求和/求差，再下一拍合并，之后单独处理横向符号。
  最终位移/指令语义保持，结果比原版晚 3 个 FPGA 时钟（50MHz 时为 60ns）。
  新目标和无效/禁止状态仍优先取消旧管线，未放宽任何时钟约束。

## 验证

- 麦轮回归：33 组 HDL 仿真、28 项上游 Python 测试、21 项集成 Python 测试（含新增的 2 项增量构建约定测试）通过。
- 新 PI 与冻结修改前实现：4000 组固定种子随机/极值输入、208087 个周期检查通过，
  原始输出、积分和 PWM 逐周期一致，包括 +/-32768 边界、反馈钳位、增益/前馈极值和中途禁止。
- 新轮速估计与冻结修改前实现：307 个采样结果对比通过，并检查 40 时钟内完成；
  覆盖正反向满桶、计数/周期切换、停止衰减、位置回绕、随机换向与缺失采样溢出故障。
- 新位置环与冻结修改前实现：600 组采样结果一致，包含采样后输入继续变化、横向反转、
  编码器回绕、航向和新目标/禁止取消；原正反 360/720 度和 3.5m/4m 边界仿真也通过。
- 共享轮速模块的原有回归：双轮 1kHz 核心、M/T 估计、PI 两个 PWM 限幅配置通过。
- 冻结完整整机：结果见证据目录 `full_system.json`，本报告在该仿真通过后才发布分支。

数值等价参考文件位于 `tests/mecanum/reference/`，只参与仿真，不进入 Gowin 工程。
位置环在完整整机仿真编译后清理了一处空白行；字节哈希变化与 token 序列不变证明保留在
`whitespace_cleanup.json`，实际编译输入哈希保留在完整整机结果中。

## 队友工程与边界

直接打开 [完整 Gowin 工程](../projects/mecanum-pipeline-opt-20261103/README.md)。
该目录包含 96 份冻结源文件、相对路径 `sensor.gprj`、CST/SDC、Tcl 和构建脚本，
无需开发机绝对路径。`build.tcl` 执行全流程，`synthesis.tcl` 仅综合，`pnr.tcl` 在综合后继续。
构建脚本不设置先前的 1800 秒硬超时，也不执行下载。
随附完整旧整机 `.pr` 压缩基准，构建仅使用整机增量布线；解压/哈希/约束校验失败即停止。
该基准已完成 P&R，但有 1 个 setup 违例，另有既有脉宽/时钟路由余项，不能视为时序通过。
源码根目录顶层仍保留参数默认值；交付的完整工程冻结为雷达原始点模式 `LIDAR_RAW=1`。

尚未测量本优化版综合资源、最差路径或 P&R 总耗时，不能声称已降低到某个占用或耗时。
已有 camera_pclk_d PR1014/负脉宽余项及运动时 IMU I2C NACK 仍需分别解决。
离线长距离/整圈仿真通过不等于落地距离/角度精度验收通过。
