# 示教记点与低速遥控

运行版本 `unified-teach-20261103`，入口 `http://127.0.0.1:8874/` → **遥控 / 示教**。
本次只修改上位机，复用已上板的导航 SRAM 固件，不修改 RTL、布局布线、SRAM 或 Flash。
用户选择稍后连接小车，本轮不做实际运动测试。

## 使用

1. 连接小车网络，点击“连接底盘”，等待新鲜遥测后“接管控制”。连接操作会在后台按当前出口 IP 配置 PC 回传，保留 Nano 端点。
2. 如有实测标定，先导入；保持车体静止并按需在底盘页完成 IMU 校零。摆好固定起点和车头方向，勾选确认，点击“设置起点 / 新建示教”。
3. 按住方向盘、方向键或 WASD 移动；Q/E 旋转。松手自动发 STOP，等待未使能且静止至少300ms，点击“记录当前位置”。建议保持车头朝向不变。
4. 路径点至少相隔150mm（固件到点容差100mm），最多16点。默认路径速度30mm/s，上限50mm/s。可撤销末点、命名保存、载入、导出/导入 JSON。
5. 把车放回同一个起点、车头对齐原方向，重新勾选并“确认已回到起点”。这一步是人工对位，系统不识别搬运位置，也不自动寻回起点。
6. 点击“上传路线并校验”，等待固件提交成功后“从固定起点自动跑”。上传不使能；开始才复用导航 STOP/CLEAR/ARM/START 握手。

没有实测标定时，按标称轮径记录的路线只能保存为草稿，不能上传自主任务。录完后不能直接套入另一组运动比例；必须先导入实测标定，再重新示教，防止坐标被默默重新解释。路线保存在 `host/runs/routes/<UUID>.json`，可导出备份。

## 接管与停车

- 正常完成动作、松开遥控、保存/记录路径点均保留接管，无需每次解锁。每次运动仍使用固件自身的停机/使能握手。
- 红色全局 STOP、Esc、遥控页空格、失联、动作故障会撤销接管，须重新接管。
- 按住遥控使用独立80ms续租、300ms截止；普通浏览器心跳不能续遥控。命令线程独立检查截止时间，即使HTTP轮询停止，也不继续发目标/心跳。固件250ms租约保持原值。
- 手势序号、释放墓碑及接管代次阻止松手后迟到的开始/续租重新驱动车辆。更换窗口焦点、隐藏页面、离开遥控标签、进入文字输入框时，正在进行的遥控停止。
- 遥控复用已验证 V3 相对位置/旋转闭环，不重新启用已删除的速度协议。轴向限1～2计数/10ms；对角限1。单次为有限距离目标，不自动串接下一段。遥控由人判断障碍，不宣称自主避障。

## 坐标与审核

手动 P4 坐标每次新目标会归零，不能用它累计示教位置。`teaching.py`独立读取 M4 原始四轮计数和 P4 IMU yaw，使用与 `mc_nav_odometry` 相同的轴向组合及实测 Q16 量化比例，累积到起点坐标系。IMU校零、复位/重连、超过350ms的接收间隔、姿态过期、编码器跳变和越界均令示教坐标失效，已有路线仍可保存。读取真实接收时刻，不能把处理积压包的时间当作新鲜采样。

已审核：按键松手/开始乱序、worker独立截止、ARM前后的过期处理、STOP优先、模式互斥、回放前提交校验与起点确认、原点重置、符号/计数回绕、同点重复、导入事务性、目录穿越、异常/正常完成的接管差异。未发现需修改 FPGA 的问题。
