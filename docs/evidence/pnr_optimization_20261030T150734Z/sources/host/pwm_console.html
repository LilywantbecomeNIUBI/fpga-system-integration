正在连接串口状态…

只输出固定 PWM，不使用 PI 或编码器反馈。慢衰减：IN2固定高，IN1低电平为驱动（手册反向），20%表示驱动时间20%；启动先11唤醒1.1ms，停止00。当前诊断固件：10 kHz，单轮 0～20%，每次最长 5000 ms。连接、刷新和恢复串口都不会自动启动。

单轮示波器测试

先把示波器设为 Single，再点“输出一次”。每次点击只测一次，到时停车；不循环、不自动重试。切换窗口或隐藏页面也会停车。
