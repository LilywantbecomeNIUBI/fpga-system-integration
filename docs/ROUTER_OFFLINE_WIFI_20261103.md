# 无广域网路由器的本地控车

车辆上位机只与 FPGA 的 UDP6206/6205 通信，不依赖互联网或 Codex。
电脑切到无互联网的车载路由器 Wi-Fi 后，Codex 会话可能失去云端连接；本地控制台可继续独立运行。

之前打开的窗口使用 `--telemetry-bind 192.168.50.10`，这是电脑有线地址。
拔掉有线后，该窗口的绑定地址和板端 PC 回传地址不能直接沿用到 WLAN。

操作顺序：

1. 停止动作，关闭旧的麦轮上位机。
2. 拔掉电脑通往车载路由器的网线。
3. 双击桌面“麦轮无线控制”或仓库根目录 `start_mecanum_wifi.cmd`，自动连接已保存的 `CMCC-rDtN-5G`。显示“无 Internet”可以继续使用本地控车。
4. 也可先手动连接该 Wi-Fi，再运行通用入口 `start_mecanum_router.cmd`。
5. 启动器会检测当前到 FPGA 的出口地址，配置 PC 回传目标，再打开上位机；点击“连接设备”查看状态。

两个入口均不发送运动命令、不修改 Nano 第二端点；通用入口不切换 Wi-Fi，无线入口按显式参数连接指定的已保存 Wi-Fi。均不更改系统路由或广域网设置。
取得的 WLAN 地址必须位于 `192.168.50.0/24`，不能与 FPGA `.30`、Nano `.20` 或其他设备重复。
切换回有线时，也按同样方式关闭旧窗口并重新运行启动器。

启动器是本机 Python 程序，Codex 临时离线时也可以运行。
如需同时在线与 Codex 联调，可另用手机 USB 网络共享或第二块网卡提供互联网；车辆控制仍走车载 LAN。
本次没有切换用户的 WLAN，也没有实际验证无线链路。

若提示 WLAN 地址不在 192.168.50.x，先保持车体停止；需要检查路由器 DHCP/LAN 网段或为 WLAN 设置一个不冲突的 192.168.50.x/24 地址，不能据“已连 Wi-Fi”判断 IP 已匹配。
