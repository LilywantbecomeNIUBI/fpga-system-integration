本版本将 `codex/mecanum-integration-20261103` 与 Nano 修复/冻结基线合并进 main，
使用标签 `milestone-mecanum-nano-20261103` 标记阶段性联调成果，不表示最终整机签核。

## 组合版本

- FPGA：`mecanum-iofix-hil-20261103`，构建 `20261102T204810Z`，位流 SHA256
  `301375bdc7a0986f922ff4993270adc94a04d638824f10f2bb3c58d8ca80ef51`。
- 麦轮与 IO 修正提交：`2ffa423`；保留所有此前雷达、网络和摄像头时序优化，使用队友完整 IO_PORT 属性。
- Nano：合入 `8e173f7` 的视频流/过期帧率修复、`a855820` 的稳定取流验收，以及 `73b8aaa` 的运行版本冻结。
- Nano 默认运行目录仍为 `/home/liwei/robot_releases/nano-video-20261103`，代码、配置、模型只读，
  日志在独立 runtime 目录；本次 Git 合并不覆盖该目录、不切换 systemd 服务。

Nano 修复采用两个独立的持续视频流，经公共入口跳转到源服务，解除新增 Nano 页面中的 10/20 FPS 软件上限，

## 合并后核查

- Nano 网页、接收延迟、UDP、系统控制、麦轮协议及引脚/电气约束回归通过，Nano 页面 JS 检查通过。
- 活动 FPGA RTL 与已上板 IO 修正版逐文件 SHA256 一致（构建时的 LIDAR_RAW=1 参数替换单独核对），无需因纯软件合并重跑 FPGA 布线或重新下载。
- Nano 固定源码包内 55 个文件的 SHA256 全部核对通过。
- 通过公共网页入口追加 8 秒并发 MJPEG 取流：原图 228 个不同帧键、28.36 FPS；识别 222 个不同帧键、27.56 FPS。
  这是实际交付帧率，不是 JSON 中的底层接收 FPS。详见 `evidence/milestone_merge_20261103/live_video.json`。

## 已验收与余项

实板已验证 MPU6500 WHO=0x70、校准、M4/P4 网口遥测、COM15 CLEAR/ARM/STOP、250 ms 看门狗、
四轮架空 1.1 秒前进、最终 PWM/速度全零，以及图传和光流在线。前进最大 PWM 9.6%。
冻结 RTL 的全点测试逐项比对 12000 点并通过；雷达实板因用户未接线明确暂缓，不能把离线通过当实板通过。

仍需保留：

- PCLK 的 MPW −0.849 ns 与 PR1014，完整时序 signoff 仍为 false。
- 电机 PWM 运行时 IMU 累计 4 次 NACK，随后恢复；需继续检查带电机干扰的通信稳定性。
- 雷达实板接入、落地横移/定角/里程精度、长时间带载运行尚未验收。
- 原双轮自动导航未直接接到麦轮；当前使用队友麦轮位置闭环。
- Git 源码中的新 M4/P4 接收支持不意味着 Nano 固定运行镜像已自动切换；新协议看板/控制展示应作为独立版本开发与发布。
