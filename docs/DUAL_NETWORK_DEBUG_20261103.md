## 在线读取方式

上位机每次连接会记录完整 M4/P4 反馈与发出的命令，文件位于：

- `host/runs/telemetry.<PID>.jsonl`：逐帧反馈及命令，单文件最多5MB，另保留一个轮换文件。
- `host/runs/live_status.<PID>.json`：按进程独立的当前状态，附带导出时间和电机/IMU数据年龄。
- `host/runs/live_status.json`：保留兼容入口，多窗口时不用于判定唯一当前来源。

只读检查命令：

```powershell
python tools/mecanum/observe_live.py
python tools/mecanum/observe_live.py --seconds 10 --out runs/wireless_observation.json
```

读取器只选取已连接、非演示且未过期的真实反馈；旧窗口、过期快照不会被当作当前状态。
不占用 UDP6205，不发送命令，可与上位机并用。在线协助时可以读取这些文件来分析四轮速度/PWM、位移、航向、到达状态及新增IMU错误。
上位机持续记录不代表聊天智能体在每一刻自动监测或自动发出报警；需要分析某次动作时，在聊天中指出动作即可读取对应记录。

## 以后启动

保持 iPhone USB 网络共享开启，再双击桌面“麦轮无线控制”。该入口连接已保存的车载 WLAN，配置 PC 回执到当前无线地址，再打开上位机。
若切换手机或网卡导致地址改变，重新启动入口即可重新检测。不要同时运行两个运动控制窗口。
