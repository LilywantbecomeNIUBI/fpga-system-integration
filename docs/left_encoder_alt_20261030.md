# 左编码器换脚候选与可用IO盘点（2026-10-30）

当前ADC复用版本左AB使用P7-25/B17、P7-26/B18。为比较输入管脚和载板走线，独立准备左AB换脚固件；不修改解码器、PI、右轮、驱动输出及电机保护。不预先认定旧IO或电路损坏。

## 选定的独立备选

|编码器线|新P7|FPGA球号|原载板信号|载板取线点|
|---|---:|---|---|---|
|左E1A|31|F16|ENC1_CLK|J_ENC1 第3脚（CLK）|
|左E1B|32|E17|ENC1_DO|J_ENC1 第4脚（DO）|

两路均约束为LVCMOS33输入。须先拔掉原ENC1/MT6701模块及信号连接，避免DO输出与D157B编码器相连。J_ENC1第1脚是载板3.3V输出，第2脚是原CS，第5脚为GND；只使用已核对的信号脚及共地，不并联D157B和载板电源输出。

P7针号与FPGA封装坐标相对旧脚更分散，但不保证实际PCB线长或物理距离，也不代表换了供电Bank。单靠封装坐标不能判断芯片内部距离。本候选用于对比IO/走线，不能证明或排除Bank供电问题。

构建入口：`python tools/build_motor.py --left-encoder-alt`。独立工程为`build/motor_left_alt/motor.gprj`，位流为`build/motor_left_alt/impl/pnr/motor.fs`。标准`build/motor/`和`hardware/pins.csv`保留原映射。下载工具必须显式加`--left-encoder-alt`才选择本候选，并校验固定哈希；默认仍选择标准目录。

候选CST与标准CST对比只改变left_enc_a（B17→F16）、left_enc_b（B18→E17），无重复球号。所有其余约束保留。构建和离线检查不代表已经下载或板级通过。

候选构建完成：Setup/Hold违规均0，源码哈希与构建记录一致。P&R引脚报告确认左AB为F16/2、E17/2，右AB为C18/2、D19/2，均为LVCMOS33（仍在Bank 2）。候选位流SHA256为`be049edb9456adf52f59454b9aff5829289c93f32b4ee524b8d79c6b81ddd78c`。
