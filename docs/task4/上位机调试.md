# 任务四导航诊断台

默认页面 http://127.0.0.1:8876。双击仓库根目录 start_task4_console.cmd 启动离线模式；没有ARM/START/DRIVE按钮，不会自动运行或续租导航。

## 启动方式

```powershell
# 演示：醒目标注合成数据，STOP禁用
python host/task4_console.py --demo
# 静态观测：原网关先移交实际UART，此处COM13只是示例
python host/task4_console.py --serial COM13 --record runs/task4_static_001
# 故障后按原节奏回放原始记录
python host/task4_console.py --replay runs/task4_static_001/chunks.jsonl
```

串口115200，由本工具独占，不自动关闭其他网关；只读模式仅在用户显式点击STOP时发送停车。退出不改变电机状态，也不替控制器续租。

## 任务运行中观察

原任务工具 tools/task4/mission.py run 新增 --record runs/task4_run_001 参数。新M2固件、接线和实测标定确认完成后，按原任务命令运行并加此参数，再另开终端：

```powershell
python host/task4_console.py --follow runs/task4_run_001/chunks.jsonl
```

任务CLI独占串口，网页只跟随日志，不抢串口。跟随模式的STOP禁用；通过任务CLI的Ctrl+C/finally STOP、显式取消与FPGA看门狗停车。日志停止更新后网页变为过期，旧输出许可不作为当前许可。

在Nano运行服务时，可用 ssh -L 8876:127.0.0.1:8876 用户@Nano地址 转发到电脑；服务仍只监听Nano的127.0.0.1，不需要第二个串口读取器。

## 页面功能

逐层检查导航帧、电机与IMU遥测、雷达包/规划推进和输出许可；显示FPGA位姿轨迹、路径点索引、v/ω、故障位、状态变化时间线及原始字段。可导出诊断快照，校验/下载标定与路径点配置包；配置导出不写设备，不含ARM/START，待标定JSON会被拒绝。

记录目录必须是新目录。chunks.jsonl含完整接收字节和主机接收时刻；接收时间不是FPGA采样时间。记录错误明确显示，出故障时保留原始记录和快照，不只留截图。

## 定位顺序

|现象|优先检查|
|---|---|
|有电机遥测但无导航帧|是否仍烧旧固件；任务四需要C3 3C 04 01|
|雷达包计数不动|M2-14/B16、共地、电平、供电、921600接收链；包数不是扫描圈数|
|雷达错误持续增加|串口/线缆/电平/校验；当前是聚合错误计数，不能全算作CRC错误|
|运行中规划不推进|结合故障位、租约、IMU/雷达健康及记录；未启动时不推进正常|
|禁止输出但faults=0|现协议不能区分近障锁存、覆盖不足、VFH无候选，页面明确标未知|
|faults bit1|IMU或雷达健康失效，单凭这个合并位不能区分是哪一个|
|faults bit5|导航租约过期，查控制器及串口所有权；诊断页不替它续租|
|许可允许/目标非零，轮速零|查电机ARM/faults、PWM反馈、D157B供电及新接线|
|轮速正常，位姿尺度或方向错|查CPR、轮距、编码器方向、IMU轴/符号/零偏|

计数回退提示可能复位或切换记录，清空速率和轨迹参考；正常32位回绕采用模运算。遥测过期、串口失败、回放结束时，许可显示未知。

## 更精确的下一步

现固件没有上传72扇区、候选方向和完整禁止运动原因，本页面不会伪造这些数据。建议下一版在50MHz域加独立诊断快照：配置有效位、IMU/雷达年龄、front_known、hazard与代次、VFH found、FIFO水位/溢出、规划状态/耗时、目标/安全航向及72位掩码；在许可下降沿锁存前后状态，再低频输出。显示/网络背压不能进入控制环。本轮未修改RTL。
