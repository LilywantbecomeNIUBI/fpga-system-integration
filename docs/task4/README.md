## 实现与边界

```text
左右编码器位置 ── mm/count ── 差速增量 + gyro 互补融合 ── 相对 x/y/yaw
                                                        │
16 个路径点 ── 当前线段投影 / 速度相关前视点 ── RPP-Lite ──┤
                                                        ↓
STL-27L UART → CRC/插值 → 32 深度点 FIFO → 72 扇区 RAM → VFH+
                                                        ↓
                             距离/时效/所有权安全仲裁 → v/ω
                                                        ↓
                            左右轮计数/10ms → 原 motor_core / PI
                                                        ↓
                                      独立输出许可门控 → D157B
```

- 采集、里程计、导航寄存器、规划、安全仲裁、底盘适配全部使用 `clk50m`。不产生新的派生时钟，1ms 和 10ms 均为时钟使能。
- 相机和以太网保留各自的 84MHz/125MHz 实现与已有 CDC。没有向这些域的组合路径添加导航逻辑，也没有把视觉状态总线直接拉入控制环。本版导航依据编码器、IMU 和 LiDAR；视觉继续独立观测。
- 本版不需要新增 84/125MHz → 导航数据通路。以后消费视觉约束时，必须接完整快照 mailbox 或异步 FIFO，分别同步释放复位；禁止把多位状态分别双拍后当作原子快照。可复用现有 `vision_mailbox.v`；连续数据可参考教材第16/35章 FIFO，另做满空、复位、停钟和背压测试。
- 数学单元用多拍有符号乘法、64位恢复除法、整数平方根和 CORDIC，不引入浮点或单拍通用除法。位姿为 mm Q16、航向为 0.01° Q16；串口遥测才换算成易读单位。
- 控制周期 100Hz。RPP 在当前路径线段上投影，选择 `projection + clip(speed × lookahead_time)`，到点切换线段。它不是跨多线段的完整 Nav2 控制器；拐角可停车调整。当前坐标/路径点限制为起点周围 ±16m，最多16个点，不做 SLAM 或全局重规划。
- VFH 采用 72 个 5° 桶，`floor(angle/500)`，候选方向取桶中心。每桶至少两个连续有效回波才确认，保留最近完整访问、独立过期；无效回波/未知区域不能当作自由空间。
- 近障膨胀采用 `ceil(asin(Rsafe/d)/5°)+1` 的保守离散形式；距离双阈值迟滞、左右最小转弯半径圆盘掩码、窄谷中心/宽谷边界和目标候选、目标/当前/历史方向代价。历史方向保存为世界方向，每轮重新换到车体坐标。
- 点云尚未按逐点位姿去畸变；初测采用默认低速，并联合实测扫描时效、角速度、距离阈值与车体余量。不能把寄存器支持的数值范围直接当作已验证的实车速度范围。
- 正常速度下无 valley 时，按零线速度重算掩码，只有全部旋转区域已知且有足够空间时才允许原地调整。绕障时，原 RPP 前视点暂处车后不再阻止沿安全 VFH 方向前进。V1 仍可能在 U 型障碍等局部极小场景停车，不声称具备全局完备性。
- STOP/减速距离按雷达测得距离定义。`robot_radius_mm` 必须包住以雷达原点为中心的整个机器人足迹；非中心安装须将偏移也计入半径，不能直接填写车体半宽。雷达角度支持偏移与反向，当前未实现平移外参逐点变换。

## 安全与启动

导航不会生成 CLEAR/ARM；原电机核心保留上电锁定、显式 ARM、STOP、轮速保护和250ms看门狗。导航有独立200ms命令租约，重复序号不能续租，陀螺仪/雷达有独立新鲜度检查。FIFO 溢出锁存为不安全，需复位排查；路径计算有20ms执行超时。

新近障原始点先锁存危险，绕过规划等待。一个新危险不能被旧直方图扫描清掉：清除要求输入 FIFO 已落地的危险代次与扫描代次一致。安全许可失效时，立即屏蔽四个 IN 输出并向轮速环给零目标；门控保持到原核心停机，避免结束任务时旧 PWM 重新露出。该门控不是额外 PWM 调制器。机械制动距离仍需实测。

配置必须在未 ARM、任务停止时写入；参数均为寄存器。启动要求确认掩码为15、各字段在支持范围、所有路径点已写入、IMU/LiDAR新鲜、原电机核心已经显式 ARM。默认几何、编码器比例、确认掩码为0。修改雷达外参后先等待至少一个数据过期窗口，让旧角度桶退场；专用上位机工具已执行这段等待。

`calibration.pending.json` 保留用户已知的65mm轮径；左右每圈计数、轮距、包络半径、IMU轴/符号/零偏及雷达朝向全部为空。协议工具会拒绝这个文件生成可启动配置。仿真使用的280mm/1500计数等数字仅是测试夹具，不是车辆标定数据。

陀螺仪沿用已有 ICM-42688 配置（`GYRO_CONFIG0=0x26`，±1000°/s）；100Hz零阶保持下，每个原始计数对应的航向步长为2000个 `0.01° Q16` 单位。可修改 `gyro_step_q16`，互补权重默认192/256；不把PC显示姿态或50Hz串口遥测用于里程计。竖直轴与零偏必须实测。

## 接线与队友优先级

队友雷达观察工程的 RX 为 **D19 / P7-36**，当前整车已用作右编码器 B，禁止直接拼接该 CST。现有雷达 TTL 输出也不能继续驱动右编码器 B。新增 `lidar_rx` 已分配至J_DRV2-14、P7-20/B16，要求3.3V兼容的 UART 输出与共地；不会控制雷达电机或发送调速命令。

完整 PnR 默认使用 `hardware/task4_m2.json` 的已确认分配；单独 STA harness 只复用已有时钟/复位/调试 UART 管脚，验证新导航的50MHz内部时序。它把两路虚拟接收接在同一输入并注入虚拟传感器，**不是整车固件，不得用于实车导航**。

构建脚本在发现其他高云构建时退出，保留准备好的独立快照，不结束队友进程；`tools/task4/`构建与离线测试工具不调用烧录器。后续经用户明确要求，使用独立调试脚本下载了M2静态候选，原默认顶层的位流已被替换；Flash未改。再次上板仍须核对最终引脚、隔离电机动力并确认候选身份，实车导航须先完成物理标定。

## 复现

从仓库根目录运行：

```powershell
python tools/task4/test.py
python tools/task4/build.py --mode syn
python tools/task4/build.py --mode pnr --harness
# 引脚确定、队友完成后，才生成真正整车候选：
python tools/task4/build.py --mode pnr
```

`test.py` 写出 `build/task4/validation.json`、逐项日志、原始协议输出、运动学轨迹和源码 SHA256。完整顶层数字测试沿用已有相机/IMU仿真接口，检查手动底盘与视觉/IMU隔离、旧无刷输出恒低和混合遥测。它不模拟真实摄像头的电气质量，也不能替代实车任务验收。

`build.py` 将当时全部源码复制到时间戳目录，禁止边改源码边编译的混用。STA/综合结果只适用于各自 `manifest.json` 的冻结版本。综合成功不等于时序通过；harness 时序通过也不等于含视觉的整车时序通过。

标定完成后，先离线生成只含配置/路径点的包，不含 ARM/START：

```powershell
python tools/task4/mission.py prepare --calibration <实测配置.json> --mission docs/task4/mission.example.json
```

上板后的台架入口是 `mission.py run`，需显式提供串口、已验证的轮向 flags、Kp/Ki；工具独占 UART，进入时先 STOP，检查遥测与配置拒绝计数，之后才按 CLEAR→ARM→START 顺序执行，每50ms续租，异常/超时/退出均 STOP。原 Nano 网关需先移交串口，不能与它同时打开。当前原网关不支持新增导航操作码，不能从旧调参页直接启动本任务。

首轮实车依次验收：悬空命令/轮向、无障碍折线路径、偏置箱子、正前箱子、突然近障、绕障后回到原路径点、终点停车、IMU/LiDAR断线、PC/Nano断连停车。本文不把理想仿真的距离/轨迹当作这些项目的通过证据。

## 寄存器与协议

复用16字节 `A5 5A / version=1 / CRC16-CCITT-FALSE` 格式。操作码 `0x40` 写寄存器（arg0地址，arg1低16位，arg2高16位），`0x41` 写路径点（arg0索引，arg1 x，arg2 y，arg3速度），`0x42` 从固定起点开始，`0x43` 心跳，`0x44` 取消。STOP=0始终优先；自动模式收到手动 DRIVE 会停机并要求重新 ARM。

完整32项地址表见 `tools/task4/protocol.py::REGISTER_NAMES`。关键参数包含机器人半径/余量、减速/停车距离、速度/角速度、前视范围/增益、到点距离、迟滞阈值、三项代价权重、两轮独立尺度、IMU融合与雷达朝向。运行中不允许改配置。

新增48字节遥测：`C3 3C 04 01`，低字节在前，末尾CRC16。包含任务/许可/故障、路径点索引、x/y/yaw、v/ω、左右目标、前方距离、规划/雷达包/错误/拒绝计数。可与原 motor/encoder/IMU 包共用 UART；原上位机忽略这个新类型，专用解析器支持混流重同步。

## 依据及复用

队友前端只逐字复用 `stl27l_uart_rx.v` 与修复过的 `stl27l_node_parser.v`；没有复制其 D19约束、观察顶层、XY ROM 和36桶区域大归约。UART实际速率、真实录包字段、错误CRC和跨零插值在本工程重新验证。来源路径与哈希见 `sources.json`。
