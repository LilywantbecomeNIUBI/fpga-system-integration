# lidar_scan_source RAM 重构记录（2026-11-02）

完整实现：[`fpga/navigation/lidar_scan_source.sv`](../../fpga/navigation/lidar_scan_source.sv)。模块端口、48 字节帧协议和 `frame_crc` 均未修改。

## 实际修改

1. 原 `working[72]`、`snapshot[72]` 改为单个 256×24 简单双端口同步 RAM。Bank 0 使用地址 0～71，Bank 1 使用 128～199；一个读口、一个写口，带 Gowin `syn_ramstyle="block_ram"` 属性。RAM 本体没有复位赋值。
2. 发布整圈时只记录旧写 Bank 为快照并翻转 `bank_sel`。计数器用 72 拍逐地址清空新写 Bank；复位后也走同一清空流程。不存在整圈复制、整圈清零或同拍多地址写入。
3. 点处理分为锁存及 `/500` 分箱、同步读旧值、比较并单地址写回三个阶段。FIFO 出队另占一拍。状态机串行处理同一扇区的连续点，避免读改写冲突；换圈首点一直保留到清空结束。
4. 打包通过共享读口取得 12 次单地址读取结果，带一拍返回标记，逐次移入 288 位寄存器。点更新读优先，打包读取可暂停；因此是 12 次读授权加 RAM 返回延迟，发生仲裁时会增加等待拍数。集齐后才启动原有 CRC，再按 `valid/ready` 输出。
5. 新增 32 点同步 RAM FIFO。实际解析器每个包会连续输出 12 个点，输入没有 `ready`，单靠“雷达平均速率低”不能保证换圈清空期间不丢点。FIFO 同时保存到达时间、错误计数和内部丢点计数，保持整圈判定与实际到达顺序一致。
6. FIFO 满时拒绝新点并记录丢点；受影响的圈不会发布，后续干净整圈可以恢复。没有新增外部接口，诊断坏圈标志也反映未处理完的丢点。
7. 修正超时与 CRC 完成竞态：扫描过期时取消读取和待发帧；已经启动的 CRC 完成后丢弃结果，再允许复用快照 Bank，避免迟到的 CRC 有效脉冲恢复过期帧。

## 相对建议作出的调整

- **仅在发布新快照时翻转 Bank。** 当旧快照因上位机阻塞尚未发完，或者新圈未满足 200 ms 上传间隔时，继续逐拍清空并复用当前写 Bank。每次换圈都翻转会写坏仍被发送端持有的旧快照。
- **增加输入 FIFO 和溢出拒绝机制。** 这是在保持输入端口不变的条件下，兼容解析器突发输出和 72 拍清空所需的缓冲。
- **共用一个同步读口。** 点读与打包读取分时仲裁，避免通过额外异步读口重新引入动态多路选择器。

## 保持的判断规则

- 角度必须小于 36000；每 500 单位为一个扇区。
- 距离、强度均非零才更新；取最小距离，距离相等时保留先到点的强度。
- 到过扇区即计入覆盖数，即使该点距离或强度无效。
- 下降超过 18000 判定换圈；圈内/换圈角度间隔不得超过 1000。
- 完整圈要求无解析错误、无输入丢点、覆盖不少于 60 个扇区；首次换圈后才开始收集。
- 发布最多 5 Hz，每圈六个分块、每块十二个扇区；扫描 400 ms 过期，输入空闲超过 250 ms 停止收集。诊断帧仍为 200 ms 一次，分块之间优先发送。

## 综合结果

工具为 Gowin V1.9.12.04，器件 GW5AT-LV138PG484AC1/I0。两版均以 `lidar_scan_source` 为独立顶层，使用相同选项、默认 100 MHz 综合约束；旧版来自修改前备份。这与完整工程中的 11,909 LUT 统计口径不同。

| 项目 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 扫描逻辑自身 LUT（不含 CRC 子模块） | 11,702 | 1,189 |
| 总 LUT（含 CRC） | 12,034 | 1,521 |
| 总寄存器（含 CRC） | 5,288 | 2,323 |
| BSRAM | 0 | 5 |
| 独立综合关键频率路径逻辑层数 | 12 | 12 |
| 综合估计 Fmax / MHz | 97.755 | 87.172 |

自身 LUT 减少约 89.8%，含 CRC 的总 LUT 减少约 87.4%。网表确认扫描缓存是 **1 个 SDPB**，输入 FIFO 是 **4 个 SDPX9B**；并非仅加属性却仍使用寄存器阵列。最终综合没有 warning/error。

用户原工程报告的 24 层没有在本次独立顶层对照中复现，不能声称相同工程条件下已从 24 层降到 12 层。这里的 Fmax 是综合估计；首次重构验证未运行完整融合工程的布局布线，也未生成或下载新位流。后续 M2 静态版本的实际布线与下载结果见下文。

原始结果位于 `build/lidar_scan_ram_20261102/`：`synthesis_comparison.json`、`optimized/impl/gwsynthesis/scan_syn.rpt.html`、`baseline/impl/gwsynthesis/scan_syn.rpt.html`。`compare_synthesis.py` 可复现独立综合对照。
