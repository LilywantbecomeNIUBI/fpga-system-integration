# 任务四 M2 接口新接线（2026-10-31）

用户确认使用载板 J_DRV2/DRV2，移除 DRV8323，两轮有刷控制、四路编码器和雷达全部迁入。M2 的9路数字IO正好够用，M1无需新增分配；IMU保持P7-39/F19 SCL、P7-40/F20 SDA。

J_DRV2-2可作共同信号地；雷达、电平转换和D157B逻辑参考地共地。接口1脚在旧载板资料中为NC，不作为雷达5V供电脚；雷达另用其规定的供电。11/12是原模拟监测口，不作GPIO。按接口针号接线，不按目测左右位置推断。

所有FPGA输入按3.3V电平使用。J_DRV2-29/30原为PWM，载板可能保留R_PD25/R_PD26下拉；若编码器调理板用弱上拉或双向MOS管转换，应检查下拉负载及实测高电平，必要时处理对应下拉，不能只靠FPGA内部上拉抵消。J_DRV2-14原为FAULT_N，DRV8323必须保持移除。

**旧位流会把部分新输入脚固定输出低。断电改线，新接线必须与M2专用新位流配套；不得在旧程序运行时直接接入编码器或雷达输出。**

新约束只用于 `system_task4_top`。`hardware/pins.csv` 和原调车顶层未改，原调参程序仍按旧接线。新顶层已移除旧M2固定低输出端口，避免与复用管脚冲突；M1旧驱动输出仍固定低。

构建入口：`python tools/task4/build.py --mode prepare` 或 `--mode pnr`，自动使用 `hardware/task4_m2.json`；无须额外指定雷达球号。已检查9路映射、球号唯一、IMU保留和完整顶层展开。2026-10-31完整M2候选Place3/Route0已完成PnR并下载SRAM，Setup/Hold为0/0；MPW仍未决，不属于完整时序签核。串口双向、IMU及未ARM零输出已验证；雷达、编码器手转、驱动动作与物理标定继续待测，见[M2静态上板记录](M2上板验证_20261031.md)。旧独立STA报告不能当作新引脚整车签核。

依据：本地 Carrier_Hall_RevB 的 `GPIO_40Pin_映射.csv` 和 `接口与丝印说明.md`；用户确认不再使用DRV8323。
