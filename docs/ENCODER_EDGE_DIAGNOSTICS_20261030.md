# 编码器只读边沿诊断与PC摄像头（2026-10-30）

目的：用户观察到左轮反向明确转动，而A边沿解码净计数仅+4。用独立被动统计区分输入边沿缺失、滤波抑制及相位导致的正负抵消。保持当前A边沿控制算法、±2步进和invalid=0语义；不改变PI、方向默认值或任何其余保护。

每轮新增九个32位累计：同步A/B边沿、滤波A/B边沿、A相正/负事件、B相正/负事件、滤波后对角变化。A相正事件为A=B，B相正事件为A≠B，均为未应用reverse的原始相位符号。对角变化只作被动诊断，绝不接入faults。计数不能区分特定电气根因，也不能把合法来回变化等同于实际轮子往返。

独立48字节帧：C3 3C 02，axis字节（1左/2右），uint16序号，模式A2，AB电平字节（高两位同步、低两位滤波），九个uint32（上述顺序），uint16保留0，CRC16小端。每秒共10帧、左右交替，每轮5Hz；原电机状态帧保持20Hz，控制仍100Hz。复用完整帧UART仲裁第二槽位，保持电机状态优先。只在独立brushed_motor_top启用诊断；旧PWM诊断顶层默认不启用。

主机按encoder_diagnostics类型独立保存，不将其输入IMU、里程计或控制状态机，不用诊断帧刷新电机遥测时效。串口重连清除旧诊断。调参页独立显示新鲜度，原invalid=0不是质量判定。shared/encoder_analysis.py计算模32位计数差及正负抵消比例，拒绝明显重置与不同通道/模式；不能由净值为0断言轮子没动。

7组RTL回归与34项Python完整回归通过，新增的抵消/重置分析单测随后通过。UART端到端测试实际解码原电机帧与新诊断帧并验证CRC和身份；独立解码台覆盖四起始相位、两方向、两种reverse、短毛刺及B相畸变，检查原始与滤波计数。前端计数清零Node回归通过。
