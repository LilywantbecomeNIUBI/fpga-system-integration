# 麦轮与 Nano 联合网页 2026-11-03

采用一个网址、两个页签。PC 运行 http://127.0.0.1:8874/；“底盘调试”直接通过车载路由器控制 FPGA，“Nano 感知”内嵌现有 Nano http://192.168.50.20:8872/。顶部保留底盘状态、Nano 遥测状态和全局 STOP，也可单独打开 Nano 页面。

## 启动

双击仓库根目录 `start_robot_web.cmd`。启动器按到 FPGA 的实际路由选择有线或无线地址，配置 PC 回传端点，保留 Nano 端点，然后打开浏览器。若本机已有统一网页服务则复用。网页初始未连接，不自动 ARM；点击“连接底盘”仅监测，之后“接管控制”才可执行。

开发启动：`python host/mecanum/web.py --telemetry-bind 192.168.50.100`。该命令本身不配置 FPGA 端点。监听仅限本机回环地址，适用于电脑经车载 Wi-Fi 无线调试；当前不向手机或其他电脑开放运动控制入口。

桌面 GUI 和网页共用 PC UDP6205，不能同时连接。切换时先停止动作并关闭/断开原控制台。有线与无线切换后断开网页连接并重新运行启动器选择新地址。

## 功能与控制行为

- 定角 ±720°、相对 X/Y ±4000mm、任意方向移动至4000mm；可配置速度上限、到达时限与轮速 PI。
- 轨迹、位置、航向、四轮原始编码器、速度、PWM、IMU 通信诊断及静止校零。
- 复用桌面控制台 MotionSession / CalibrationSession 的 STOP、清错、ARM、目标确认与 FPGA 反馈检查。新网页未复制另一套运动算法。
- 浏览器控制租约互斥；每100ms心跳，超过600ms未续约则向工作线程请求 STOP。隐藏页面、关闭页面或显式停止也撤销控制。服务器失效时由现有 FPGA 250ms命令看门狗停机。
- STOP 可从另一窗口触发。FPGA 复位或遥测断流后不自动重连、不恢复运动。再次执行需要明确连接、接管及执行。
- 同源和随机请求令牌检查；无跨域控制接口。Nano 页保持只读，不把视觉结果接入自动运动。

编码器速度字段是原始计数/10ms，换算时不乘 control_shift；位置字段与外环速度上限采用控制计数。PWM 字段单位为千分比，显示百分比除10。

## 验证及边界

离线19项检查通过：新增网页租约/请求检查10项、扩展运动5项、路由器传输4项。Playwright 使用 Edge 验证了页签切换、运动模式切换、未接管时执行禁用，以及浏览器实际连接后新鲜的电机和姿态数据。截图保存在 `output/playwright/unified_chassis_live.png` 和 `unified_nano_live.png`。

实车仅接收遥测，没有执行网页运动或校零；观测时四轮速度与 PWM 为0、未使能、轮速闭环1000Hz。状态快照见 `docs/evidence/unified_web_20261103/live_readonly.json`。因此尚不能将离线检查视为浏览器运动的实车验收。

Nano 固定版本 nano-video-20261103 未改动、未切换。图像与推理可在内嵌页实时显示；其遥测接收器在 FPGA 重启后仍为 restart_required，雷达/底盘旧缓存保持明确警示，需恢复 Nano 接收服务后再验收雷达显示。本机默认 SSH 密钥登录不可用，未擅自修改冻结部署。底盘网页直接读 FPGA 的实时遥测不受 Nano 旧缓存影响。
