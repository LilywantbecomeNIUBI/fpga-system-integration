# D157B 双路有刷电机 FPGA V1

这是独立电机候选固件，工程位于本仓库 `fpga/motor/`，不会删除或替换 `fpga-balance`、`fpga-FOC` 的无刷实现。后续系统集成可实例化 `motor_core`，直接提供命令脉冲和接收状态；UART 顶层用于独立调试，不与旧串口协议兼容。

## 已实现的逻辑

- 两路 AB 正交编码器：两级同步、稳定采样滤波、四倍频有符号位置、10ms 速度窗口、对角跳变统计。正计数序列为 `00→01→11→10→00`。保留方向，不取绝对值。
- 左右轮独立开环 PWM 或有符号 PI 速度环；增益使用 Q8，独立积分限幅和条件积分抗饱和。PI 运算拆为七个时钟阶段，控制周期为100Hz。全程使用50MHz时钟及使能信号，不生成低速逻辑时钟。
- 电机极性与编码器极性分别配置。改变配置需要先停机再 ARM，不能运动中切换极性/模式/增益。
- PWM 默认10kHz，使用 `PWM/0` 和 `0/PWM` 快衰减。00为滑行。每次从零输出启动时，先执行约1.1ms的11刹车态唤醒，再进入PWM；这是芯片手册1ms唤醒延迟的处理，避免低于5us的PWM高脉冲无法可靠唤醒。禁用/急停始终覆盖唤醒并输出00。
- 正常指令变化每10ms最多变化20‰，默认占空比硬限幅±300‰。这是待调试配置，不代表已验证的电机安全电流。STOP、故障和急停不经过斜坡，直接关闭输出。
- 换向先降到零，再要求编码器速度在±1计数/窗口内并维持10个控制周期；不能在仍有运动反馈时直接反向加压。反向静止启动同样先满足等待条件。
- 上电默认锁存停机；必须先 CLEAR，再 ARM。ARM 本身目标为零，随后才接收 DRIVE。STOP 允许重复序号。
- 250ms有效运动指令看门狗；无效、坏CRC、重复/旧序号帧不会续期。外部急停异步撤销ARM和输出，释放后经过同步链，必须重新CLEAR/ARM。
- 异常计数保护：任一轮每10ms超过8次非法AB跳变、速度绝对值超过4096计数/窗口、或占空比绝对值≥100‰且连续约500ms无编码器增量，均锁存停机。上述阈值是初版诊断值，需根据实际编码器校准；它们不是电流或真实车速保护。
- 115200 8N1串口命令、CRC校验、序号校验、残帧超时，以及20Hz状态快照。

本模块不读取电流、不闭环控制转矩，也不能通过无编码器运动保护证明发生机械堵转。D157B ADC是电源电压分压输出，此固件未采集。

## 速度单位和电机资料

当前速度目标与反馈均为 **编码器四倍频计数/10ms**，开环单位为占空比千分数。每输出轴转的计数未确认，不提供伪精确的RPM或m/s。

用户提供的商品截图列出MG513P10/P20/P30/P60四种12V电机：额定电流0.36A、堵转电流3.2A、约4W，并标注电枢电阻2.3Ω±0.5、电感4.45mH；标称1:20实际为1:20.45、标称1:60实际为1:61.36。截图没有Xp28这一行，也没有编码器分辨率；不能据此选定本机减速比。图片参数作为用户提供的参考，不是本车测量或电流限值。

用户确认电机使用防呆6Pin插座直接连接D157B，本阶段不要求重新排线。FPGA侧AB输入电平仍需确认/转换为3.3V；防呆插座不提供电平转换。完整线序不作为当前软件实现的阻塞项。

测得输出轴一圈为N个四倍频计数后：`RPM = velocity × 6000 / N`。轮径D以米计：`m/s = velocity × 100 × π × D / N`。如果N已在输出轴测得，不再乘减速比。

## 构建与离线验证

```powershell
python tools/test_motor.py
python tools/build_motor.py --prepare-only
python tools/build_motor.py
```

工具：Python3、Icarus Verilog、Gowin Designer V1.9.12.04。默认Gowin目录为 `C:/Gowin/Gowin_V1.9.12.04_x64`，可用 `GOWIN_HOME` 指定。工具不下载固件，不打开串口。受限进程中Icarus可能无法运行，需在允许执行本机工具的终端运行。

生成工程为 `build/motor/motor.gprj`，顶层 `brushed_motor_top`，目标GW5AT-LV138PG484AC1/I0。引脚来自 `hardware/pins.csv`，仅接底盘、板载时钟/复位/LED/UART及两路固定低的旧驱动使能；此独立固件不包含摄像头、网口、IMU、雷达或音频。不能用它替代全系统集成动态验收。

时序约束仅对UART与AB输入同步链第一级D端设置异步例外；PI及所有内部路径按50MHz检查，无整模块false path或放宽内部运算的multicycle。外部异步接口的电气特性、编码器最高输入频率及急停恢复行为仍需实测。

## 串口协议 V1

命令固定16字节，多字节数值均为小端。CRC16-CCITT-FALSE：多项式0x1021、初始0xFFFF、无反射、无最终异或，覆盖前14字节，CRC本身低字节先发。

| 字节 | 含义 |
|---|---|
| 0..1 | A5 5A |
| 2 | 版本1 |
| 3 | STOP=0 / ARM=1 / DRIVE=2 / CLEAR=3 |
| 4 | 8位序号 |
| 5 | bit0速度闭环；bit1/2左/右电机反向；bit3/4左/右编码器反向；其余必须0 |
| 6..7 / 8..9 | 左/右有符号16位目标 |
| 10..11 / 12..13 | Kp / Ki，Q8无符号，范围0..4096 / 0..1024 |
| 14..15 | CRC16 |

ARM仅在已清故障、停止状态、目标为0时有效；闭环Kp必须非0。DRIVE目标范围：开环±1000‰，闭环±1024计数/窗口；实际输出仍受±300‰限制。DRIVE必须复用ARM时的flags、Kp/Ki。序号相对上次接受的ARM/DRIVE前进1..127才有效，允许255回绕0。ARM/CLEAR不会接受运动目标。残帧20ms超时；CRC、版本错误帧计入bad_frames，策略拒绝计入rejected_commands。

状态固定48字节，CRC覆盖前46字节：

| 字节 | 含义 |
|---|---|
| 0..2 | C3 3C 01 |
| 3..5 | 最后接受的运动序号、armed、配置flags |
| 6..7 | 故障位：bit0上电/外部急停，bit1命令超时，bit2编码器非法跳变，bit3计数速度越界，bit4无编码器运动 |
| 8..11 / 12..15 | 左/右位置 int32（模2^32回绕） |
| 16..19 / 20..23 | 左/右速度 int32 |
| 24..25 / 26..27 | 左/右斜坡后占空比 int16，尚未计入1.1ms唤醒等待 |
| 28..31 / 32..35 | 左/右累计非法跳变 uint32 |
| 36..39 / 40..43 | bad_frames / rejected_commands uint32 |
| 44..45 / 46..47 | 遥测包序号 uint16 / CRC16 |

外部急停会清除配置与拒绝计数，重新ARM前重建控制配置。位置/非法跳变计数仅在板级复位时清零。普通STOP/CLEAR不清位置。

## 主机工具

```powershell
python -m pip install -r requirements.txt
# 只读监测，不发送ARM/DRIVE；用实际端口替换COMx
python host/motor_console.py --port COMx --action monitor --duration 10
# 单独发送STOP
python host/motor_console.py --port COMx --action stop
```

显式 `--action run` 才会先STOP、CLEAR、ARM并以50ms周期发送DRIVE；需收到状态确认才能进入运动。默认目标均0、默认开环、运行时长0.5秒，上限10秒；通信异常会停止发送运动命令并尝试STOP，FPGA另有250ms看门狗。`--left/--right`设置目标，`--closed-loop --kp/--ki`选闭环，`--motor-reverse`与`--encoder-reverse`均以bit0表示左轮、bit1表示右轮。增益只用于计数域控制，未经实车整定，不应直接用供应商例程的数值替代。

在AB电平转换、P7旧网络断开、急停回路和轮子悬空检查完成之前，不执行run。当前交付只完成离线实现和验证，不自动触发上述运行过程。
