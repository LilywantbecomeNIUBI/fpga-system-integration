# M1 / M2 纯 PWM 自助测试台

启动：

```powershell
python host/pwm_console.py --live --serial-port COM13 --port 8874
```

打开 `http://127.0.0.1:8874/`。默认不加 `--live` 时仅为离线页面。当前已连接实板的会话由这个程序独占 COM13，旧闭环网关和一次性诊断脚本应保持退出，不能同时运行。

1. 选择 M1（左轮，PWM=P7-21、另一输入=P7-22）或 M2（右轮，PWM=P7-23、另一输入=P7-24）。
2. 用 5/10/15/20% 档或数值框设置占空比，输入 100～5000 ms（步进1ms）。当前 FPGA 诊断固件固定 10kHz、上限20%、单次硬件上限5000ms。
3. 确认双轮悬空、人员远离；如需抓波，先把示波器设置为 Single。
4. 点击“输出一次 M1/M2 PWM”。程序自动完成零输出确认和专用诊断 ARM，然后仅发出一次限时测试；不自动循环或重试。
5. 查看占空比曲线、本次内部 PWM 脉冲数、引脚回读脉冲数和有效驱动累计时间。可以导出 CSV；原始串口和命令自动记录在页面显示的目录。

STOP 按钮和空格键随时停车；切换窗口、隐藏页面、页面心跳或遥测超过200ms、串口重连都会撤销测试。FPGA 保留250ms有效指令看门狗和不可续期的5000ms输出时限。连接、刷新、恢复通信不会自动解锁或产生非零输出。

当前是专用纯 PWM 诊断固件（状态 flags=0x22），没有 PI 或编码器参与控制，视觉/IMU 暂不运行。内部计数及引脚回读只用于电气测量，不是轮速反馈，也不能证明轮子已经转动。正常闭环上位机不会被用于此固件；如果载入其他固件，本页会禁用测试。

验证：9项PWM控制台Python测试通过；RTL仿真覆盖慢衰减有效占空比、11唤醒、5秒硬时限、STOP、看门狗及引脚回读。2026-10-29用户确认修正后电机测试正常；该结果不代表闭环、平衡或整车运行验收。

新版时长可输入100～5000ms，步进1ms，固件单次硬上限5秒；需下载新版固件（flags=0x22）。

慢衰减修正：测试时IN2固定高，IN1低电平为01驱动，高电平为11刹车（手册反向）。占空比表示有效驱动时间，20%对应IN1低20%、高80%。启动先11唤醒约1.1ms，计入单次总时长；停止、0占空比和复位输出00。引脚回读统计01驱动区间。上限5秒、20%、单轮及看门狗保持。不要外接拉高线。
