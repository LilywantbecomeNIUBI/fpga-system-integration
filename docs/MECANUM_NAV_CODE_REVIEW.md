## 综合截断警告分类

没有批量屏蔽综合警告。保留日志中的EX3791并按接口范围审阅：

  先用s64再右移20得到Q16。角度最大180°，结果落在s32。
* cell_index的8bit next_r已由恢复除法比较约束为0..49，可写u7。
* odometry原始轮增量超过2048锁存故障，正常和<=8192，标度<=65536；位移Q16可写s32。
  速度缩窄前新增s64比较/标志/提交三级，超s16范围立即锁存而非环绕。
* raymap的16bit测距与标定偏移/任务位置范围内，移位后的s64乘积写s32毫米不会溢出；
  sweep单元最多1264mm半径的格心差，旋转局部坐标写s32。
* path_target任务坐标±4000mm、里程计保护±16000mm；线段长度<=11314mm，目标距离
  <=28285mm，整数结果可缩到对应s32/u16。nav_math异常有独立出口。

## 全量实现后的修复复核

* PA2122：旧VFH距离表的SP读优先写模式不受GW5AT支持。改为显式同步SDP，
  状态3请求、30捕获、24使用，数据/observed/binary标签仍对应同一i；无RAM复位，
  填表与读阶段不重叠。226个参考场景及226个综合后SDPB模型场景逐项一致。
* 坐标服务的21条互斥乘法语句原来映射31个乘法宏。改为32位有符号操作数寄存、
  状态54单乘法、状态55按寄存slot提交p0..p3并按return返回，保持64位乘积与原舍入。
  整机综合已确认服务乘法宏31→2，整机MULT27X36从79→50、Logic85738→80171。
* 原生角度分箱原来组合除500，现复用nav_math串行除法。atan接口已验证范围
  ±18000厘度，16位归一化结果0..35999零扩展后相除；217个分箱边界一致。
* 新旧服务1536组检查点、5376个乘积逐位一致；验证有符号坐标、系数、速度、
  旋转臂长和负角。故障中止会先撤销许可并回IDLE，未完成的slot不能提交电机目标。
* 复核非阻塞赋值：MUL读上拍已锁存操作数；COMMIT读上拍乘积；之后的SUM状态
  才读取已更新p0..p3。角度相除启动后的等待状态不复用上一笔math_done。
* 规划完成时先清plan_valid，三轴轮速转换全部完成后才写command_epoch并恢复许可。
  乘法多出的42拍和分箱除法不到100拍均在既有20,000拍服务余量中，不放宽50ms预算。

修复后的完整时序、物理CDC、扇出与拥塞仍须以对应冻结目录最终报告验收；
综合资源变小和软件等价本身不代表时序已经闭合。

* 地图复位原先直接依赖多位时间戳差的组合比较。位偏斜回归已在旧服务复现短暂
  误复位，新版用单一clk50寄存条件消除该毛刺；公共复位仍异步断言，真正传感器
  过期最多延迟一拍清图，且立即停车许可不依赖该寄存器。过期恢复必须重新完整扫描。
  此修复需重新核对物理复位释放/Setup/Hold，不新增false path掩盖它。

* 数学复用精简：路径只调用op0/1/2，坐标服务只调用op1/3/4；新增编译期OP_MASK，
  在启动与busy分支均加常量保护，避免仅拒绝启动却仍保留未用数据通路。默认11111
  保留旧调用者行为；禁用操作和非法busy模式有明确错误出口，不能停在busy死锁。
  1734个新旧数学对照、58248个逐周期检查及16组导航bench通过；有效操作结果、
  握手、周期与原版一致。旧Task4整机回归及新版物理实现单独重跑，不沿用旧版位流。
